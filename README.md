# MiracuVerse v2

Originele, responsive fanwebsite geïnspireerd door de informatiearchitectuur van Miraculous.to. **Geen kopie van hun broncode, afbeeldingen of video's.**

## Functies
- Home met featured episodes, countdown en Discord
- Episodes met catalogus van seizoenen 1–6 en specials, zoeken, sorteren, seizoentabs en bekekenfilter
- Afleveringsdetails en lokaal opgeslagen bekeken-status (geen video-hosting)
- Global search (ook Ctrl+K)
- The Show met verhaal, seizoenen en personages
- Music placeholder, Community, themawisselaar en responsive menu
- Countdown en Discord-link instelbaar in `config.js`

## Publiceren
GitHub Pages → Settings → Pages → Deploy from branch → main → root.

## Let op
Titels zijn gebaseerd op de publiek zichtbare episodecatalogus en moeten waar nodig redactioneel worden gecontroleerd. Er is geen automatische synchronisatie met externe releases. Er worden geen ongeautoriseerde streams of beschermde posters aangeboden. Accounts, echte streaming, een backend en muzieklicenties zijn niet inbegrepen.
